# ART_DUST2.md — de_dust2 美术方向（合法纹理与视觉氛围）

> 目标：让地图在视觉上"神似"CS 1.6 的 dust2——走进去老玩家一眼认出——同时**所有美术资产合法来源**。
> 本文档管视觉/纹理；几何还原见 `MAP_DUST2.md`。两者分开做：先锁几何灰盒，再贴美术。

## 核心红线（必读）

- **绝不使用 Valve 的任何纹理/贴图/模型/美术资产。** 不提取、不转换、不临摹。
- **不做"像素级复刻原版纹理"。** 照着原版纹理做"几乎一样"的贴图＝制作衍生作品，同样侵权。私下自己玩也不行。
- 合法路径是：用**原创**或**正版/CC0 授权**的纹理，做出和 dust2 **同一类材质、同一种氛围**的观感，但每张贴图都是干净来源。
- 参考：CS2 重制 dust2 时也是**重新制作**美术，没有复用 1.6 的纹理。我们走同样的路。

## 设计目标：抓"氛围辨识度"而非"复制贴图"

dust2 的视觉辨识度主要来自这些**可以合法重现的整体特征**，而不是某一块砖的具体纹路：

1. **色调**：中东沙漠的暖色调——土黄、沙色、赭石色为主，整体偏暖、偏亮。
2. **材质类型**：砂岩/砖砌墙面、沙土地面、木质箱子、金属门/护栏、混凝土构件。是"哪类材质"对了就神似，不需要具体纹路一致。
3. **光照氛围**：强烈的日照感，明亮的户外，清晰的阴影。dust2 给人的是大白天、视野通透的感觉。
4. **整洁的可读性**：表面不过度做旧、不堆砌噪点，敌我和轮廓清晰——这既是 1.6 的传统，也是竞技可读性的要求。

**判断标准**：做出来的地图截图，让老玩家瞬间联想到 dust2 的"那种感觉"，但把任意一张贴图单独拿出来和原版并排，是明显不同的原创纹理。

## 材质清单（按类型，全部用合法来源）

为每类表面准备一套 PBR 材质（albedo / normal / roughness 等），来源见下节：

| 表面类型 | 视觉方向 | 用在哪 |
|---------|---------|--------|
| 砂岩/砖墙 | 暖土黄、砂砾感、规整砌块 | 建筑外墙、各通道墙面 |
| 沙土地面 | 浅沙色、轻微颗粒、可带脚印感 | 户外开阔地、道路 |
| 石板/混凝土地 | 偏灰的硬质地面 | 室内、炸点地面 |
| 木箱 | 暖木色、木纹、钉/边框 | 各处掩体箱子 |
| 金属门/护栏 | 做旧金属、暖灰 | 门、猫道护栏 |
| 装饰构件 | 拱、柱、窗的中东建筑风 | 拱门、建筑细节 |

## 合法纹理来源（给 Claude Code 和负责人）

按授权友好程度排序，**使用前务必核对每个资产的授权条款**：

- **CC0（公共领域，最省心）**：
  - ambientCG（ambientcg.com）— 大量 CC0 PBR 纹理，有砖、沙、木、金属
  - Poly Haven（polyhaven.com）— CC0 纹理 / HDRI / 模型
  - 这类可商用、可改、免署名，最适合本项目
- **原创自制**：用 Substance Designer / Painter、或 Blender 程序化生成自己的纹理
- **正版素材市场**（注意看授权范围）：Quixel Megascans（在符合其授权的前提下）、各 PBR 素材站的授权素材

> ⚠️ 不要从"CS 纹理包""dust2 材质下载"这类来源拿图——那些多半是 Valve 资产的再分发，是雷区。只用上面这种**通用、授权明确**的纹理库。

## 给 Claude Code 的实现约定

1. **几何先行**：在 `MAP_DUST2.md` 的几何灰盒锁定（打了 `dust2-geometry-v1` tag）之后，再开始贴美术。不要在几何没定时就上纹理。
2. **材质做成可替换资源**：每类表面一个 Godot 材质资源（`.tres`），集中管理，方便整体调色调、换纹理。
3. **Claude Code 能做**：下载/导入 CC0 纹理、配置 PBR 材质、把材质挂到对应几何、调 UV 缩放、配置环境光照与 HDRI、做整体色调统一。
4. **Claude Code 不能做**：原创美术绘制、手工建模精细装饰。这些由负责人外部提供或用 CC0 现成资产顶替。
5. **每个引入的外部资产，在 `ASSET_CREDITS.md` 登记**：资产名、来源、授权类型、链接。这是合法性的凭证，也方便日后审查。
6. **不确定某来源是否合法 → 记入 `DECISIONS_FOR_REVIEW.md`，不要用**，交负责人判断。

## 光照与氛围（合法、靠配置实现）

- 用一张沙漠/晴天的 HDRI（CC0，Poly Haven 有）做环境光与天空，立刻有 dust2 的户外白天感。
- 主光源模拟强日照，暖色温，清晰阴影。
- 整体后处理偏暖、对比适中，保持通透可读，不压暗、不过曝。
- 目标是"大白天的中东据点"，而不是阴间滤镜。

## 验收（视觉）

- 老玩家看截图能联想到 dust2 的氛围。
- 任一贴图与原版并排是明显不同的原创/CC0 纹理（合法性自检）。
- `ASSET_CREDITS.md` 完整，每个资产来源授权可查。
- 不破坏几何阶段的可读性和可跳点判断。

## 与原版的关系（一句话总结）

**几何可以几乎一致（合法），视觉做到神似（合法），但纹理本身必须是干净来源——不复制、不临摹原版美术。** 这样你们既能找回 dust2 的感觉，又不给项目埋版权雷。
