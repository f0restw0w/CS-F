# MAP_DUST2.md — de_dust2 灰盒重建规格

> 目标：用纯灰盒（greybox）重建 de_dust2 的**空间几何**，供 Phase 0 在熟悉的空间里测移动手感。
> 只复刻几何结构，**不**复刻任何 Valve 美术资产。

## 版权前提（必读）

- de_dust2 的**布局/几何不受版权保护**，可以合法重建。
- **绝不**导入或转换原版 `.bsp`、贴图、模型、音效。全部用 Godot 原生几何体（`BoxMesh`/`CSGBox3D`）+ 纯色材质搭建。
- 这是灰盒，目标是空间记忆对得上，不是视觉还原。

## 单位约定

- 沿用 `MOVEMENT_SPEC.md` 的方案 A：**1 Godot 单位 = 1 GoldSrc/Quake 单位**。
- 下面所有尺寸都是 GoldSrc 单位（约等于英寸）。直接当 Godot 单位用，移动公式零换算。
- 玩家参照尺寸（GoldSrc 标准，务必照此，手感和卡位才对）：
  - 站立碰撞体：宽 32 × 32，高 72
  - 下蹲高度：约 36
  - 眼睛高度（站立）：约 64
  - 最大可跨上台阶高度（step height）：18（关键！dust2 很多边沿靠这个能不能上去）
  - 标准跳跃可越过高度：约 44–45（配合 step 后更高）

## 整体布局

de_dust2 是双炸点地图，T 出生在一侧，CT 出生在另一侧，中间通过**中路(Mid)**、**A 长道/A 短道**、**B 隧道**连接。俯视大致结构：

```
                 [CT 出生点]
                /     |      \
          A区 ←—     中路Mid    —→ 拱门/B区
          /            |            \
    [A点 Bombsite]   双门Doors    [B隧道 → B点 Bombsite]
          \            |            /
           \      [中路下]         /
            \         |          /
              ＼  [T 出生点]   ／
                 \    |     /
            A长道  T 通道们  B通道
```

> ⚠️ 上面是示意。实际方位以你的肌肉记忆为准——你比任何图都清楚长 A 在哪、双门朝哪开。Claude Code 按下面分区尺寸搭，搭完由负责人在游戏里走一遍校准方位。

## 分区规格

下列尺寸是社区通行的近似值，**作为起点**。负责人（前职业选手）进游戏后凭手感/记忆校准，校准后锁定到地图场景里。每个区域用灰盒方块拼，地面、墙、箱子分别用不同灰度区分。

### T 出生点 (T Spawn)
- 开阔区域，约 768 × 512 的平地。
- 多个出生位，原型期摆几个 Marker3D 即可。
- 通向：A 长道方向、中路下、B 通道方向。

### CT 出生点 (CT Spawn)
- 类似开阔区，约 768 × 512。
- 通向：A 区（经 CT→A 的连接）、中路、拱门。

### 中路 (Mid)
- 一条长直道，是 air strafe / 连跳测试的黄金地段。
- 长约 1024+，宽约 192–256。
- 中段有**双门 (Double Doors)**：两扇可通过的门洞，门框宽约 64 每扇。原型期门做成固定开着的洞口即可，不做开关动画。
- 中路连接 T 侧下方与 CT 侧，并岔向 A 短道(穿门后上 A)。
- **中门 (Mid Doors / Xbox 区)**：中路靠 T 侧有标志性的箱子（"Xbox"），高约 64，可跳上。是经典卡点和连跳测试点。

### A 长道 (Long A)
- dust2 最长的直道，**air strafe 和连跳的最佳测试场**。
- 长约 1536+，宽约 256。
- 一端连 T 侧(经 Long Doors)，一端通向 A 点的 Pit(坑)和开阔地。
- **Long Doors**：长 A 进入处的双开门洞。
- **A 大坑 (Pit)**：长 A 末端下沉区，比主地面低约 64–128，CT 可下去卡点。

### A 短道 / A 拱门 (Short A / Catwalk)
- 从中路穿门上来通往 A 点的路径，含一段**猫道 (Catwalk)**。
- 猫道是抬高的窄道，宽约 128，比下方地面高约 64–96。
- 测"跳上/跳下高低差 + 落地保速"很合适。

### A 点 (A Bombsite)
- 开阔下包区，约 640 × 640。
- 标志性掩体：几个箱子堆，高度分别约 64 / 96 / 128，可逐级跳上（测连跳上箱）。
- "Goose"、"默认架点位"等掩体用不同高度的灰盒方块表示。

### B 隧道 (B Tunnels)
- T 侧进 B 的通道，**多段拐弯 + 高低差**，测贴墙削速(clip velocity)和拐弯保速的好地方。
- 上下两层：B 上隧道 (Upper Tunnel) 和 B 下隧道，之间有坡/台阶连接。
- 通道宽约 160–192。

### B 点 (B Bombsite)
- 开阔下包区，约 640 × 640。
- **B 平台 (Plat)**：抬高的平台，高约 128，可跳上，是经典架点。
- 掩体箱子若干，高度 64–128。

### 拱门 (CT → B / Mid 拱门)
- 连接 CT 出生与 B 点 / 中路的拱形通道。
- 拱门洞高约 128，宽约 192。

## 灰盒搭建约定（给 Claude Code）

1. **全部用 `CSGBox3D` 或 `BoxMesh + StaticBody3D + CollisionShape3D`** 搭，方便快速调尺寸。
2. **不同用途用不同灰度材质**区分，便于辨认：
   - 地面：中灰
   - 墙：浅灰
   - 可跳箱体/掩体：深灰或带色（醒目）
   - 可通过门洞：留空，不放碰撞
3. **每个区域做成独立场景**（如 `mid.tscn`、`long_a.tscn`），再在 `dust2.tscn` 里组装。方便单独迭代某个区。
4. **关键可跳点要标注**：在编辑器里用注释或 Marker3D 标出"这里应该能连跳上去""这个高低差是 step 能上的"，方便负责人验证。
5. **出生点用 Marker3D** 占位，不做实体。
6. **尺寸都暴露为可调**或集中在常量，因为负责人几乎肯定要按记忆校准。

## 校准流程

1. Claude Code 按上述近似尺寸搭出完整灰盒。
2. 负责人进游戏，用熟悉的身法走一遍每个区。
3. 记录"这条道感觉比记忆短了""这个箱子应该一跳能上但上不去"等。
4. 调尺寸 → 重测 → 锁定。
5. 锁定后该版本打 git tag（如 `dust2-greybox-v1`），作为布局基线。

## 几何极致还原（高保真目标）

> 目标：建筑、路口、门、箱子等**几何形态与空间关系**做到与 1.6 几乎一致。
> 这一节针对的是**几何**——不受版权保护，可以放手还原。纹理/视觉见 `ART_DUST2.md`，受版权约束，走合法路径。

### 还原原则
- **空间关系优先于绝对数字**：哪个门对着哪条道、箱子之间的相对位置和高低差、各 angle 的视线通断——这些对得上，老玩家就认得出。绝对尺寸是负责人记忆校准的对象。
- **可跳点逐一还原**：1.6 每个能跳上的箱子、能 duck-jump 的台、能卡的沿，都要在几何上复现对应高度（参考玩家尺寸：step 18、跳跃 45、duck-jump 更高）。这些是肌肉记忆资产。
- **门洞尺寸影响走位**：门的宽高决定能不能并排、能不能贴框过、急停卡门的手感，按记忆校准。

### 逐区还原清单（几何形态）

下面列出每个区**需要还原的几何要素**，Claude Code 据此把灰盒细化。具体数值仍以负责人记忆为准，记入 `DECISIONS_FOR_REVIEW.md`。

**中路 Mid**
- 双门：两扇独立门洞，中间门柱，门洞宽度还原（影响贴框过门）
- Xbox 箱：高度还原到"一跳能上"，位置在中路靠 T 侧
- 中路整体的宽窄变化（靠 CT 侧、靠 T 侧宽度不同）
- 中路与 A 短道、下中路的岔口位置

**长 A Long**
- Long Doors：进长 A 的双门洞
- 长 A 的长度与直度（air strafe 测试关键，要够长够直）
- 大坑 Pit：下沉深度、坑沿能不能跳出跳进
- 长 A 末端通向 A 点的开阔过渡

**A 短道 / 猫道 Catwalk**
- 从中路穿门上 A 的爬升路径
- 猫道抬高高度、宽度（窄道，影响走位）
- 猫道跳到 A 点的落差

**A 点 Bombsite**
- 箱堆的层次与高度关系（能逐级跳上）
- 默认架点的掩体形态
- 各入口（长 A、猫道、CT 方向）汇入 A 点的相对位置

**B 隧道 Tunnels**
- 上下两层隧道的连接坡/台阶
- 多段拐弯的角度（测贴墙削速）
- 隧道宽度（影响并排和走位）

**B 点 Bombsite**
- B 平台 Plat：抬高高度（架点）、能不能跳上
- 掩体箱子的高度层次
- 各入口（隧道、拱门/CT 方向）汇入位置

**拱门 / CT 区**
- 拱门洞的高宽
- CT 出生到 A、到 B 的路径长短关系

**出生点**
- T / CT 出生区的相对方位与到各点的距离感（决定开局 rush 时间，老玩家对这个有感觉）

### 还原验收
- 负责人盲走：不看纹理，光凭几何空间和走位，每个区都能认出是 dust2 的哪里。
- 所有经典可跳点都能按 1.6 的方式跳上/卡住。
- 几何锁定后打 tag（如 `dust2-geometry-v1`），作为后续贴美术的基线。

### 几何与纹理的分界（重要）
- 本文档只管**几何**（位置、尺寸、形态、高低差）——可放手还原。
- **纹理、贴图、视觉外观**属于受版权保护的美术资产，**不在本文档**，见 `ART_DUST2.md`，必须走原创/授权的合法路径。两者分开做：先几何灰盒锁定，再贴合法美术。

## 不做的事（Phase 0）

- 不做贴图、不做光照美术（默认环境光够看清灰盒即可）。
- 不做门的开关动画（门洞固定开着）。
- 不做炸点逻辑、不做出生逻辑（只摆 Marker）。
- 不做 B 门、地图边界美化。先能跑能跳能测身法。
